        Connect to GitHub

        Publishing writes your changes straight to the recipe repository on GitHub. To do that, this device needs its own access token — you only set this up once per device.

        Making a token

        1. Open GitHub's new fine-grained token page.
        2. Under Repository access, pick Only select repositories and choose this repository — nothing else.
        3. Under Permissions → Repository permissions, set Contents to Read and write. Leave every other permission alone.
        4. Generate the token and paste it below.
        Stored only in this browser, on this device. It's sent to github.com and nowhere else, and never becomes part of the site.

        Worth knowing

        Anyone who can use this browser can publish recipe changes with this token. That's a fine trade for a family recipe book — don't reuse this pattern for anything more sensitive.
